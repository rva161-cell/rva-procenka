Новый поставщик

Интернет-магазин с API — четыре поля; либо поставщик по локальному прайс-листу.
Подключение поставщика — добавьте IP нашей программы в разрешённые
Для подключения сервиса необходимо в личном кабинете поставщика добавить IP-адрес нашей программы в список разрешённых. Логин здесь — код клиента поставщика.
Найдите на сайте поставщика любой артикул и скопируйте адрес страницы с результатами, заменив артикул на {code}. Программа откроет эту страницу в браузере Chrome, сделает снимок и разберёт цены с помощью ИИ (10–30 секунд на артикул, результат запоминается на 10 минут). Если цены видны только после входа — после сохранения нажмите «Войти на сайт» в списке поставщиков.
Форматы: CSV, TSV, TXT (разделители ; , таб), XLSX. Колонки (артикул, бренд, название, цена, количество, срок, склад) распознаются по заголовку автоматически.

Массовая проценка

Файл XLSX, XLS, CSV, TSV или TXT: одна строка — одна позиция (артикул, бренд — если знаете, комментарий). Колонки распознаются по заголовкам; без заголовков первая колонка — артикул, вторая — бренд. До 200 позиций.
У этих позиций бренд не указан — выберите вариант, иначе позиция будет пропущена:
Готово 0 из 0
Ищу предложения у поставщиков — по одной позиции за раз. Вкладку можно закрыть, задание досчитается на сервере.
